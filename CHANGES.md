# История изменений Ion Pulse

Формат основан на Keep a Changelog. До первого релиза все изменения записываются
в секцию `Unreleased`, а при релизе переносятся под версию и дату.

## Unreleased

### Added

- Создан основной документ продукта и план разработки `PROJECT.md`.
- Создан словарь предметной области `CONTEXT.md`.
- Зафиксированы двуязычная модель публикаций, RBAC, редакционный workflow,
  переводы, еженедельный журнал и дайджест.
- Создан новый каркас FastAPI с версионированным API.
- Добавлены liveness `/api/v1/health` и проверка PostgreSQL `/api/v1/ready`.
- Добавлены конфигурация окружения, Dockerfile, PostgreSQL Compose-сервис,
  линтеры, статическая проверка типов и тесты.
- Добавлены модели зарегистрированного участника, ролей и множественных
  назначений ролей, а также начальная Alembic-миграция.
- Добавлены Argon2-хеширование паролей, серверные сессии и API регистрации,
  входа, выхода и текущего пользователя.
- Добавлено изменение отображаемого имени в профиле пользователя.
- Добавлена подача и просмотр собственной заявки на роль автора.
- Добавлена административная проверка заявок с автоматическим назначением роли автора.
- Добавлен фундамент публикаций: категории, публикации и локализации RU/EN.
- Добавлено создание черновика публикации в одной из четырёх начальных категорий.
- Документация запуска обновлена: локальный PostgreSQL является основным путём,
  Docker Compose — необязательным.
- Добавлены список собственных публикаций и отправка черновика на проверку.
- Добавлена ручная редакционная очередь, решения редактора и неизменяемые записи
  аудита решений публикации.
- Материал, возвращённый редактором, можно отредактировать и повторно отправить;
  при публикации создаётся сохранённое задание перевода на вторую локаль.
- Аудит редакционного workflow хранит исходное и новое состояние публикации,
  инициатора перехода и обязательную причину решения.
- Добавлен фоновый обработчик заданий перевода с блокировкой от параллельного
  захвата, сохранением локализации и защитой ручной редакторской версии.
- Публичная страница публикации возвращает готовую локализацию или оригинал,
  пока перевод недоступен; неудачные задания перевода повторяются до трёх раз.

### Changed

- Проект переименован в Ion Pulse.
- Корневая рабочая папка переименована из `habr` в `ion-pulse`.
- Локальная папка backend переименована из `habr-clone-api` в `ion-pulse-api`.
- GitHub-репозиторий переименован из `habr-clone-api` в `ion-pulse-api`.

### Removed

- Удалена прежняя реализация backend для разработки новой системы с нуля.

### Pending

- Web-экраны регистрации и входа.
